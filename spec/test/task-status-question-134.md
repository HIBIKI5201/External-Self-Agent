# #134 タスクの状態質問と待ち時間の質問の区別
2026-10-12。合成タスク、隔離DB、偽Google APIを使用。本番チャットへ検証文を送らない。
修正前に、`資料のタスクって今どうなってる？` が `brain.is_status_question` でTrue（返答時間の説明へ流れる）になることを再現。
修正後は「タスク」「#番号」「〇番」、タスク名・プロジェクト名・1件だけのタスク名に含まれる語を含む質問を待ち時間の質問にしない。`返事はどうなってる？`・`考えるの遅くない？`・`まだ？`・`どうなってる？` は従来どおり待ち時間の質問。
タスクの状態質問はモデルを使わず保存値（状態・締切）を返し、DBを変更しない。「そのタスク」は直近で最後に名前の出たタスク。候補が複数なら候補を並べて確認し、見つからなければ名前か番号を尋ねる。いずれも返答時間を答えない。
画面の送信待ちを迂回する判定は、サーバーから受け取る除外パターン（`exclude`）で同じ語を除く。
専用4検査、関連の待ち時間・照会の検査を含め成功。全体の検査結果はPRに記載。
限界: タスクを指す表現は有限のパターンとタスク名の照合。タスク名を含まない遠回しな指示（「例のあれ」など）は、直近の会話にタスクがなければ確認を返す。
