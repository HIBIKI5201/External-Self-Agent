# #117 読み上げの読みの修正
2026-10-12。VOICEVOX 0.25.1（この PC、冥鳴ひまり ノーマル）の `audio_query` の読みで確認。音は鳴らしていない。

| 文 | 修正前の読み | 発話用の文（`voice.speakable`） | 修正後の読み |
|---|---|---|---|
| 言葉がいいよ～！次は？ | イイヨ？、**ジ**ワ？ | 言葉がいいよー！次は？ | イイヨオ、**ツギ**ワ？ |
| 言葉がいいよ〜！次は？（波ダッシュ） | イイヨ、ツギワ？ | 言葉がいいよー！次は？ | イイヨオ、ツギワ？ |
| E.S. Agent | **イイ、エス、エエジェント** | エスエージェント。 | エスエエジェント |
| E.S.Agentを使う | イイ、エス、エエジェントオ… | エスエージェントを使う。 | エスエエジェントオ… |
| 10～12時に集合 | ジュウ、ジュウニジニ… | 10から12時に集合。 | ジュウカラジュウニジニ… |
| 次回もよろしく | ジカイモ… | （変更なし） | ジカイモ… |

規則（読み上げだけ。チャットの文は変えない）: 「E.S. Agent」「E.S.Agent」「ES Agent」「E.S.エージェント」→「エスエージェント」。数字・曜日の間の「～」「〜」→「から」。かな・漢字の後の「～」「〜」→「ー」。残りの「～」は取り除く。

## 検査
- `tests/test_voice.py::test_reading_fixes_keep_the_chat_text`（オフライン）: 上の変換。
- `tests/test_voice.py::test_voicevox_reads_the_fixed_text`（新しい印 `needs_voicevox`。VOICEVOX が動いていないときはスキップと表示）: 実際のエンジンの `audio_query` で「ツギ」と読み、「イイ、エス」と読まないこと。手元でエンジンを一時的に起動して成功を確認した。

限界: 聞き取りでの確認（実際の音）は未実施。読みは `audio_query` のかなで確認した。
