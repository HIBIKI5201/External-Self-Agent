# #118 会話モードの聞き違いの補正
2026-10-12。合成の文。マイクと Edge の音声認識での実機確認はしていない。

## 方式
Edge の Web Speech API は認識に言葉の候補（文法・語彙）を渡す手段が実際には効かないので、送る前に画面で直す。モデルは使わない。

## 検査
- `tests/test_listen.js`: 直る例（「五フレームの週課やる」「ウォーフレームしよう」「おいS聞こえる？」「Sが考えてる時」「ねえS、今日どう？」）と、変えない例（「四つ買った」「五個ある」「Sサイズの服」「Sランクとった」「ESの提出」「これはS」「MよりSがいい」「5フレームずれる」）。
- `tests/test_voice.py::test_listen_corrections_come_from_defaults_and_config`: 既定の対応表と設定の追加・上書き、不正な値の無視。

## 実機で確かめること（未確認）
会話モードで「Warframe の週課やる」「おい Es、聞こえる？」と話し、状態の行に「（聞き取り「…」を直しました）」が出て、送られた文が直っていること。

限界: 対応表にない聞き違いは直らない。「S」の判定は有限の言い回しで、「Sがいい」のような大きさの話と区別できない場合がある（「MよりSが」「MかSが」は除外）。
