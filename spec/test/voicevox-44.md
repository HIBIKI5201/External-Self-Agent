# #44 VOICEVOX での読み上げ

決定（Issue のコメント）: 着手する、声は冥鳴ひまり、対象は返事に加えてタイマーの知らせと猫のひとこと、
再生は Windows 側で一本化、エンジンは Es が必要なときに起動する（終了の責任も Es）。

## 環境（2026-10-10）
- VOICEVOX 0.25.1（`%LOCALAPPDATA%\Programs\VOICEVOX`）。エンジンは `vv-engine\run.exe` を画面なしで起動できる。
- 冥鳴ひまりはスタイル「ノーマル」だけ（ID 14）。初回の audio_query は約 3 秒、合成は約 1.3 秒（短い一文）。
- 規約: エンジン付属の冥鳴ひまりの規約と公式サイトで、クレジット「VOICEVOX:冥鳴ひまり」があれば商用・非商用で利用可。
  登録・同意の手続きはない。画面のバーにクレジットを常に表示する。

## 再生の方式
- `winsound.PlaySound` のメモリ再生（同期）は、別スレッドから止められなかった（5 秒の音が最後まで鳴った）。
- そのため、再生中だけ一時ファイルに書き、非同期で再生して `PlaySound(None, 0)` で止める。再生後にファイルを消す。

## 確認したこと
- テスト `tests/test_voice.py`（偽のエンジン、音は出さない）: 初期はオフ、冥鳴ひまりの ID と音量で合成、
  同じキー・3 秒以内の同じ文の重複防止、保留中の返事を読まない、停止で待ち列を捨てる、オフで読まない、
  エンジンが無い・つながらない・声が無いときに状態を返して例外にしない、試聴はオフでも鳴る、タイマーの知らせを 1 回だけ、
  Es が起動したエンジンを止める。Markdown・コード・URL の読み替えと長文の切り方。
- 開発用サーバー（8766、開発用の DB）で実エンジン:
  - 読み上げをオンにすると、Es がエンジンを起動して約 3 秒で準備OK（`started_by_es: true`）。
  - 文を渡すと約 3.4 秒で読み上げ、同じキーの 2 回目は受け付けない。停止とオフが効く。
  - オフにするとエンジンのプロセスが終わる。サーバーを強制終了してもエンジンが終わる（ジョブ）。
  - 内蔵ブラウザでバーの「読み上げ・音量・試聴・停止」とクレジットの表示、試聴中の「読み上げ中」、オフの切り替えを確認。
- `python tests/run.py`: 144 passed / 0 failed / 0 skipped。
