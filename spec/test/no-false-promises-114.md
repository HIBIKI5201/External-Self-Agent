# #114 仕組みのない約束
2026-10-12。合成の会話、隔離DB、偽Google API。本番チャットへ検証文を送らない。

## 再現
- 振る舞いの希望の決まった応答（#20）が「わかった、気をつけるね」と約束していた（修正前の main で評価 holdout の 3/3 に出現）。
- 「分類はゲームにして。次からは分類が分からない時は聞いてね」で、分類だけ変わり後半の希望には何も答えなかった（操作の経路で返事が終わる）。
- モデルの「今後は〜するようにするね」「〜する形で進めるね」「覚えておくね」がそのまま表示されていた（#109 の反映確認でも「覚えておくね」が出た）。

## 検査（`tests/test_no_false_promises.py`、オフライン 4 件）
- 約束の文の検出（4 形）と、通常の文（「これからも応援してるよ」など）を消さないこと。「覚えておくね」だけは記憶の約束として区別。
- モデルの約束を除き、正直な説明と改修タスクの提案（承認で EsAgent に 1 件）に置き換える。
- 操作と希望が混ざった発言で、分類の変更を実行したうえで希望にも答え、保存した返事も同じ。
- 雑談モードでは正直に言うだけで提案しない。

## 評価（`no-promise-dev` / `no-promise-holdout`、qwen3:8b、k=3、約束の語で判定）

| holdout pass^3（雑談モード「次からは〜してほしい」） | 0.0（毎回「気をつけるね」） | 1.0 |

最初の判定語（「今後は」）は「今後はどんなふうに話してほしい？」という質問も数えていたので、約束の語（ようにするね・形で進めるね・気をつけるね・していくね・覚えておくね）に直して前後とも測り直した。

限界: 「(a) 今の設定や記憶で実現できる希望」は、明示した記憶（「覚えて」）と、#115 で入る「分類が分からないときは聞く」動作に限られる。それ以外の希望は改修の提案になる。
