YouTubeの接続設定

Googleで接続すると、自分のプレイリストを表示し、動画を検索できます。動画はE.S. Agentの中のYouTubeプレーヤーで再生します。

  1. Google ToDoの接続で使っているGoogle Cloudのプロジェクトで「YouTube Data API v3」を有効にする。
  2. Google接続をまだ設定していない場合は、Google Cloudでデスクトップアプリ用のOAuthクライアントを作り、ダウンロードしたJSONをインストール先の secrets/google_client.json に置く。既存のToDo・カレンダー接続がある場合は同じ設定を使う。
  3. E.S. Agentの「動画・プレイリスト」から「GoogleでYouTubeに接続」を押し、開いた通常のブラウザでYouTubeの読み取りを許可する。テスト中のOAuthアプリでは自分のGoogleアカウントをテストユーザーに追加する。
  4. E.S. Agentに戻り、「自分のプレイリスト」を開く。プレイリスト内の動画、または検索結果を押すとアプリ内で再生する。

再生できる範囲

Google連携はプレイリストなどの読み取りを許可するものです。プレーヤーのログインやYouTube Premiumの機能を保証するものではありません。埋め込みが禁止された動画、年齢確認が必要な動画、非公開動画はアプリ内で再生できない場合があります。その場合は「YouTube ウィンドウで流す」で開いてください。

検索・一覧の取得にはYouTubeの利用上限があります。通信や設定の問題はYouTube欄に表示します。OAuthアプリがテスト中の場合は、接続期限により再接続が必要になる場合があります。
