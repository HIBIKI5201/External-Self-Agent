# #112 モデルが書いた提案の扱い
2026-10-12。合成の会話、隔離DB、偽Google API。本番チャットへ検証文を送らない。
修正前は、モデルが返事に「EsAgent にタスクとして追加する？『うん』か『追加する』で OK だよ」と書いても承認待ちの状態がなく、「追加する」と答えると何も追加されなかった。
修正後の検査（`tests/test_model_offers.py`、モデルの代役で返事の文を固定）:
- 提案の文の検出（3 形）と、通常の文（「買い物を追加したんだね」「どんな機能が好き？」など）を消さないこと。
- 作業モードで Es への希望に付いたモデルの提案は、コードの提案（承認・取消のボタン）に置き換わる。「追加する」で EsAgent のタスクが 1 件だけ追加され、2 回目の「追加する」では増えない。モデル呼び出しなし。
- 提案の後に別の話題を挟んだ「うん」では追加しない。
- 雑談モードでは、モデルの提案もコードの改修提案も出さない。
評価シナリオ `feature-offer-accept-dev` / `feature-offer-stale-holdout` を追加。
全体の検査結果はPRに記載。
限界: 提案の文の検出は有限のパターン。「〜しておこうか？」以外の言い回しの提案は残りうる。その場合も承認の語は有効な提案がなければ何も変更しない。
