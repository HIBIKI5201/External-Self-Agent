# #144 返事への評価の記録
2026-10-12。合成の会話、隔離DB。本番チャットへ検証文を送らない。

## 決めることの扱い
Issue の「決めること」は推奨案のとおりにした（ラベル needs-decision はなし）: ボタンは返事にマウスを乗せたときだけ（評価済みは常に表示）、対象はまずチャット画面の返事だけ。

## 検査（`tests/test_reply_feedback.py`、オフライン 2 件）
- モデルの返事に 👎、書き直し、決まった返事に 👍。種類（chat / template）、直前の会話、モデル名が保存される。ユーザーの発言は評価できない（HTTP 400）。
- 書き出し: SFT は書き直し（template を除く）、`all` で 👍 の決まった返事も入る。DPO は書き直し＝chosen、元の返事＝rejected。`data/feedback/` に書く。
- `/clear` の後も評価は残り、`/feedback` で一覧、`/feedback delete 番号` で消える。
- `/api/state` の `feedback` で画面がボタンの状態を出す。

## 実機で確かめること（未確認）
- チャット画面で返事にマウスを乗せるとボタンが出ること、✎ で入力欄（ブラウザの入力ダイアログ）が出て保存されること。内蔵ブラウザでは本番チャットに触れるため確認していない。

限界: 返事の種類は、この変更より前のメッセージには記録がない（chat として扱う）。
