# #35 猫の自動非表示

Windowsの専用チャットウィンドウをタイトル・ウィンドウクラスで識別し、可視かつ非最小化の場合に猫を隠す。
他のアプリに覆われていても非表示のまま。複数のチャットウィンドウでは1つでも非最小化なら隠す。
猫の初期表示と500msの監視で状態を合わせる。隠す際に吹き出しも閉じ、隠れている間は吹き出しを作らない。
手動有効/無効の既存経路は維持し、設定保存を呼ばない。

偽Windows APIと偽Tkで、複数ウィンドウ・最小化・閉鎖・別ウィンドウ・非表示と復帰・設定非変更・吹き出し破棄を確認。
オフライン34 passed / 0 failed / 13 skipped、モデル込み47 passed / 0 failed / 0 skipped。構文チェック成功。
ユーザー画面での新しい自動切替はマージ後の実機確認対象。
