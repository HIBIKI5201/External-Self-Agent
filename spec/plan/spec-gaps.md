## 3. 解消済み（このセッション内）

2026-10-08更新: #10のユーザー確認に基づき、猫の透明表示、ダブルクリック前面化、YouTubeウィンドウ集中連動を確認済みとした。新しい猫の自動非表示は #35 の検証記録を参照。

| Gap | 対応 |
|---|---|
| 「金曜」を木曜の日付にする | 相対日付をプログラムで変換してから渡す（AS-06） |
| できないことを「やった」と言う／作り話をする | 判断をコード側に移し、操作後の返事をテンプレート化、名乗りの打ち消し（AS-02） |
| 頼んでいないタスクを追加（2023 年の締切） | 追加の条件、過去日付の拒否、タスク名の照合（AS-04） |
| 「それぞれに締切」ができない | Qwen3 8B に変更、一括更新の絞り込み（AS-02・AS-04） |
| 雑談中にタスクの話へそれる | 相談ははっきり聞かれたときだけ、モードの明示（AS-02・AS-03） |
| 「忘れて」が効かない | 翌日まで提案から外す（AS-04） |
| `/morning` の「うん」で嘘のタイマー開始 | 提案を記録し、「うん」で本当に開始（AS-07） |
| モデル未準備でメッセージが消える | 返事待ちとして残し、準備後に自動で返事（AS-16） |
| 黒猫がいるとサーバーを再起動できない | 黒猫をタスクのジョブから外して起動（AS-01） |
| 数ターン前の会話を忘れる・聞いていないことを作り話する（#12） | 履歴をトークン予算で選ぶ、以前の発言を指す質問はコードで確認（AS-02） |
| 嘘の打ち消しで文が不自然になる（#11） | 名乗った文を丸ごと消す（AS-02） |
