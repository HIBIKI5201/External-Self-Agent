# #135 周期の語だけの追加の確認
2026-10-12。合成タスク・合成プロジェクト、隔離DB、偽Google APIを使用。本番チャットへ検証文を送らない。
修正前（#105取り込み後の main）に、`ゲームのウィークリーに「週課A」を追加して` で名前は「週課A」になるが、`repeat` が未設定のまま確認なしで登録されることを実モデルで再現。周期を明示した `…毎週月曜4時で追加して` ではプロジェクトが付かないことも再現。
修正後は、周期の語（ウィークリー・デイリー・週課・日課）だけで曜日・時刻がない追加をモデルに渡さず、登録前に周期を確認する。返事の周期・「繰り返しなしで追加」・取消・ボタンでそれぞれ1回だけ追加または取消し、最終DBの title/project/repeat を確認。同じプロジェクトにそろった周期は候補として示すだけで、承認前に使わない。
確認中の別の名前を挙げた依頼は答えとして扱わない。囲みの中の「ウィークリー」は周期の語として扱わない。使用済みの選択肢の再送では追加しない。
専用4検査、既存の繰り返し・選択肢の検査を含め成功。全体の検査結果はPRに記載。
限界: 「隔週」「毎月」は既存どおり読めない周期として確認を返す。名前の囲みがない場合は「ウィークリーに〇〇を追加」の形だけを読み取る。
