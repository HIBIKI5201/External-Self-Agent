# #109 雑談の汎用締め文・繰り返しの抑制
2026-10-12。合成の雑談（雑談モード、合成タスク）、隔離DB。本番チャットへ検証文を送らない。実モデル qwen3:8b。
評価: `tests/eval/scenarios.json` に `small-talk-specific-dev`（自然さ・定型文の指摘・ゲーム実況）と `small-talk-specific-holdout`（料理の話）を追加。各 3 ターン、k=3、各 18 返答。
同じシナリオを修正前の main（82bee80 + 新シナリオ）と修正後で比較。

| 指標 | 修正前 | 修正後 |
|---|---|---|
| pass^3（汎用締め文・「聞こえない」を含まない） | dev 1.0 / holdout 0.0 | dev 1.0 / holdout 1.0 |
| 広い語の一覧（何でも・いつでも・気軽に・遠慮なく・聞かせて）を含む返答 | 3 / 18 | 2 / 18 |
| 同じトライアル内で前の返答と同じ文を含む返答 | 1 / 18 | 0 / 18 |
| 聞かれていない自己制約（聞こえない等） | 0 / 18 | 0 / 18 |
| ターン p50 / p95 | 1804 / 2564 ms | 1694 / 3035 ms |

修正後に残った 2 件は「気軽にしてね」「ちょっとした話でも聞かせて」（文の途中）。コードの除去は、ほかに残る文があるときだけ、利用者の語を含まない「聞かせて」、「何でも／いつでも〜話して」、直近の返事とほぼ同じ文、機能を聞かれていない自己制約に限る。
限界: 試行数が少なく（k=3、2 シナリオ）、モデルの揺れの範囲を超えた改善とは言い切れない。話題の具体性・質問の適切さは人の確認（review.csv の自然さ欄）が必要で、今回は数えていない。改修提案の差し込み（#112）、決まった応答の誤反応（#113）は別 Issue。
